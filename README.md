# Director's Brief

디렉터처럼 지시하면 AI가 디자이너처럼 일합니다.
목적 6가지와 디자인 유형 22가지로 나눈 실무형 디자인 프롬프트 100개입니다.

**사이트:** https://uxidesigner-ux.github.io/directors-brief/

## 쓰는 법

1. **내 브리프 채우기**: 브랜드명, 핵심 사용자, 수익 모델 같은 정보 8가지를 한 번 적으면 100개 프롬프트의 빈칸이 모두 채워집니다. 비워 둔 칸은 `[ ]`로 복사됩니다. 입력한 내용은 브라우저(localStorage)에만 저장됩니다.
2. **고르기**: 목적 탭과 유형 칩으로 거르거나, `로고`, `상세페이지`, `042`처럼 검색합니다.
3. **복사해서 붙여넣기**: 카드의 "복사" 버튼이나 상세 화면의 "프롬프트 복사"를 누르고 Claude 같은 AI에 붙여넣습니다. 첫 결과가 나오면 같은 대화에 "다음 단계" 프롬프트를 이어 붙여 다듬습니다.

주소 끝에 `#042`처럼 번호를 붙이면 해당 프롬프트가 바로 열립니다.

## 분류

| 목적 | 개수 | 쓰는 때 |
|---|---|---|
| 브랜드 구축 | 18 | 포지셔닝, 이름, 로고, 컬러처럼 브랜드의 뼈대를 세울 때 |
| 전환·매출 | 18 | 랜딩, 상세페이지, 광고처럼 방문자를 고객으로 바꿀 때 |
| 제품 UX·UI | 22 | 앱·웹 화면, 흐름, 디자인 시스템을 설계할 때 |
| 콘텐츠·소셜 | 14 | 썸네일, 카드뉴스, 일러스트처럼 매주 만드는 콘텐츠 |
| 설득·보고 | 14 | 피치덱, 보고서, 데이터 시각화로 결정을 끌어낼 때 |

유형(로고, 앱 화면, 대시보드·데이터 등 22가지)과 결과물 형태(전략·문서, 이미지 프롬프트, HTML 코드, 디자인 명세)는 카드마다 표시됩니다.

## 프롬프트 구조

복사되는 프롬프트는 `app.js`의 `compose()`가 아래 순서로 조립합니다.

1. **역할**: 해당 분야 실무자로서의 구체적인 경력
2. **프로젝트 맥락**: 내 브리프에서 그 프롬프트에 필요한 항목만
3. **과제**: 무엇을, 어떤 기준으로
4. **진행 방식**: 단계별 작업 순서. 방향 탐색이 필요한 프롬프트는 "3안 먼저 보기 / 바로 완성하기"를 고를 수 있습니다
5. **산출물**: 받을 결과물의 형식
6. **디렉팅 원칙**: 아래 10가지 중 그 프롬프트에 맞는 것만 (상세 화면에서 끌 수 있음)
7. **자기 검수**: 출력 전에 AI가 스스로 점검할 기준. 제품·전환·검수 프롬프트에는 5대 기준 자체 채점이 붙습니다
8. **공통 지시**: 부족한 정보는 `[가정]`으로 표시하고 구조화해서 답하기

### 디렉팅 원칙 10

1. 쓰임새 먼저
2. 3초 규칙
3. 해석은 시스템이, 선택은 사용자가
4. 수익과 연결
5. 완성도는 수치로 (8px 그리드, 1.25 타입 스케일, 대비 4.5:1, 한글 본문 14px 이상)
6. 상태까지 디자인 (로딩·빈 화면·오류·성공)
7. 조작하고 싶은 인터랙션 (0.1초 반응, 되돌리기, 의미 있는 움직임만)
8. 말은 지시문처럼
9. 냉정한 근거
10. 누구나 이해하는 말

## 파일 구성

```
index.html          화면 뼈대
styles.css          스타일 (커팅 매트 + 브리프 종이 콘셉트)
app.js              필터, 검색, 프롬프트 조립, 복사, 즐겨찾기
data/core.js        목적·유형·브리프 항목·디렉팅 원칙 정의
data/p1-brand.js    001~018 브랜드 구축
data/p2-convert.js  019~036 전환·매출
data/p3-product.js  037~058 제품 UX·UI
data/p4-content.js  059~072 콘텐츠·소셜
data/p5-persuade.js 073~086 설득·보고
data/p6-review.js   087~100 검수·고도화
```

빌드 과정이 없는 정적 사이트라 `index.html`을 브라우저로 열면 바로 동작합니다.

## 프롬프트 추가·수정

`data/p*.js`에 아래 형식으로 넣으면 됩니다.

```js
{
  id: '101', p: 'product', t: 'app', out: 'code', x: true,  // x: 3안/바로 완성 선택 지원
  title: '카드에 보일 제목',
  role: 'AI에게 맡길 역할',
  ctx: ['brand', 'audience'],                    // 내 브리프에서 쓸 항목
  in: [{ k: 'screen', l: '대상 화면' }],          // 이 프롬프트에서만 받는 정보
  task: '{brand}의 {screen} 화면을 ...',          // {키}는 입력값으로 바뀜
  steps: ['...'], output: ['...'], checks: ['...'],
  next: ['다음 단계 프롬프트']
}
```
